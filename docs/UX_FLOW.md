# UX 流程

最后更新：2026-09-24

## 1. 信息架构

```text
登录
  -> 工作台
      -> 建筑档案
      -> 巡查管理
      -> 整改任务
      -> 复核归档
      -> 规范知识库
      -> 报告中心
      -> Agent 运行记录
```

## 2. 核心路径

```text
巡查人员登录
  -> 选择建筑
  -> 创建巡查
  -> 填写现场记录并上传照片
  -> 查看智能体计划和分析
  -> 提交风险

复核人员登录
  -> 打开待复核巡查
  -> 对照规范条款确认风险
  -> 创建整改任务

整改责任人登录
  -> 查看任务要求
  -> 提交整改说明和证据

复核人员登录
  -> 查看智能体证据初审
  -> 关闭或驳回任务
  -> 导出巡查报告
```

## 3. 空状态与异常状态

- 无巡查：显示创建入口和最近建筑，不显示空白表格。
- 检索无依据：显式显示“信息不足”，不允许模型补写条款。
- Provider 超时：显示降级提示，并允许继续使用预置分析。
- 权限不足：显示明确原因和可执行返回路径。
- 上传失败：保留已填写内容，单独重试文件。

## 4. 核心交互规则

- 所有提交和审批操作都有明确结果反馈。
- 风险等级不能只依赖颜色，同时显示文字和图标。
- 多步骤流程显示当前步骤和下一步。
- 驳回必须填写原因。
- 关闭任务前显示证据链和缺失项。
