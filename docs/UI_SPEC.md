# UI 规格

最后更新：2026-09-24

> UI 设计系统的事实源见 [docs/ui/UI_DESIGN_SYSTEM.md](ui/UI_DESIGN_SYSTEM.md)。本文件保留页面级视觉摘要；Token、组件状态和 Figma 映射以设计系统文档为准。

## 1. 视觉方向

采用克制、专业、数据密度适中的文保工作台风格，不使用营销式首页和装饰性大图。

- 背景：冷调浅灰纸面 `#F4F7F5`
- 主色：氧化铜绿 `#1F6F62`
- 主文字：墨色 `#1F2A26`
- 高风险：朱砂红 `#C2412D`
- 待处理：土金 `#A96F1F`
- 正常：松石绿 `#2F7D68`
- 边框：低对比灰绿 `#D8E1DD`

## 2. 字体和尺寸

- 中文：`Noto Sans SC`、`Source Han Sans SC` 或系统无衬线字体。
- 数字和 ID：`IBM Plex Mono`，系统中不存在时使用等宽字体。
- 正文最小 14 px，主要正文 16 px，行高 1.5。
- 卡片圆角不超过 8 px。
- 触控目标不小于 44 px。

## 3. 组件规则

- 使用 Lucide 图标，不使用 emoji 作为功能图标。
- 风险状态同时使用文字、图标和颜色。
- 所有可点击元素有 hover、focus、active 和 disabled 状态。
- 表单标签始终可见，不依赖 placeholder 作为标签。
- 长任务显示进度、失败原因和重试入口。

## 4. 响应式

- 1440 px：固定侧边导航和双栏工作台。
- 1024 px：侧边导航收窄，主内容保持双栏。
- 768 px：导航折叠，工作台变为单栏。
- 375 px：只保证查看、审批和轻量提交，完整巡查优先使用桌面端。

## 5. 无障碍

- 正文和背景对比度至少 4.5:1。
- 键盘可以完成登录、提交、审批和任务关闭。
- 焦点样式清晰可见。
- 尊重 `prefers-reduced-motion`。
- 图片包含替代文本或标记为装饰图。
