# Figma 主界面风格一致性审计

- 审计日期：2026-09-25
- 审计范围：`05 Desktop Screens` 的 6 个桌面页面与 `06 Mobile Screens` 的 2 个移动页面
- 用户目标：统一古朴文保档案风格，确保相同边栏、目录文字、品牌区和状态组件在不同页面中保持一致
- 证据目录：`output/design-audit-2026-09-25/revised/`

## 总体结论

修正前主要不一致集中在风险地图页：它使用 166px 紧凑边栏、不同品牌头部、工程线稿底纹和更短的素材声明，而其余桌面页面使用 192px 标准边栏。修正后，6 个桌面页面已统一为同一套 192px 边栏、品牌区、7 项导航目录、选中态、山水草木亭塔暗纹和页脚标语；移动端因 375px 场景采用独立顶部栏，属于响应式差异，不是风格不一致。

## 页面逐项结果

1. `S1 风险地图`：健康。地图已替换为低对比宣纸地形底图，风险点、图例和业务文字保持可编辑；边栏与其他桌面页完全统一。
2. `S2 巡查总览`：健康。品牌区、目录、选中态、照片标签和页脚暗纹与 S1、S3–S6 一致。
3. `S3 巡查详情与证据工作台`：健康。沿用统一边栏、字体、边框、状态色和照片声明，页面层级清晰。
4. `S4 风险复核与创建整改任务`：健康。三栏业务布局是功能差异，外层视觉语言和目录系统保持一致。
5. `S5 整改任务详情与证据复核`：健康。对比照片、完整性检查和复核操作沿用统一面板与状态组件。
6. `S6 复查归档与报告中心`：健康。报告式内容保留纸本文档气质，导航与其他桌面页一致。
7. `M1 现场巡查采集`：健康。移动端取消侧栏，使用统一深松绿顶部栏和底部主操作区，符合窄屏任务场景。
8. `M2 巡查提交确认`：健康。与 M1 的顶部栏、间距、按钮、风险色和字体保持一致。

## 已修正的不一致

- 桌面边栏宽度统一为 192px。
- 品牌区统一为朱红印章、`文巡智护` 和 `文物建筑智能巡查`。
- 导航目录统一为：风险地图、巡查总览、巡查任务、文物档案、问题处置、统计分析、系统管理。
- 导航顺序、图标、行高、选中背景和左侧金色标记统一，仅当前页面的选中项不同。
- 页脚标语统一为“保护文化遗产 / 守住历史根脉”。
- 页脚工程线稿统一替换为低透明度山水、草木和亭塔暗纹。
- 参考照片声明统一为“参考图演示素材 · 非真实证据”。
- 风险地图替换为古朴宣纸、山形、水系和道路纹理的重绘底图；保留“不展示精确坐标”的业务边界。

## 保留的合理差异

- 风险地图页需要搜索、筛选和日期；巡查总览需要指标和发起入口；详情页需要状态与上下文。这些顶部区域不同是任务结构差异。
- 移动端不复用桌面侧栏，避免占用 375px 内容宽度。
- 高风险、警告、成功和信息状态继续使用不同颜色，但均同时显示文字，不只依赖颜色。

## 可见风险与验证边界

- 部分 12px 次要文字在纸本背景上的实际对比度需要在代码实装后用工具测量；截图只能确认视觉上未被暗纹遮挡。
- 键盘焦点、触控目标、缩放重排、状态播报和动态错误恢复无法由静态 Figma 截图验证。
- 地图为演示性业务片区，不表达真实地理边界、精确坐标或未公开遗址信息。
