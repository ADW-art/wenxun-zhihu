## 2026-09-25：守迹参考图作为主要视觉方向

- 状态：已确认

- 决定人：用户
- 原因：参考图更符合文保档案、巡查和专家复核的专业场景，同时不依赖泛化 AI 视觉。

## 4. QA 矩阵

### 4.1 视觉

- 1440 × 1024、1280 × 800、768 × 1024 和 375 × 812 无内容溢出。
- 字体、状态色、边框、圆角和间距引用统一 Token。
- 页面不是卡片套卡片，不以装饰大图或空泛文案填充空间。
- 长标题、长风险描述、长规范引用和长证据说明可换行。

### 4.2 交互

- 浏览器返回、取消、重试和权限不足有明确路径。
- Loading 保留上下文，错误保留用户输入。
- Drawer、Dialog、Popover 可通过键盘打开、关闭和返回焦点。
- 风险未确认前不存在“整改中”或可创建的整改任务。

### 4.3 工程

- OpenSpec、格式、Lint、类型检查、测试和构建通过。
- 共享组件不直接依赖 Tailwind 默认状态色。
- 页面与 Figma 的差异记录在本文档或后续映射表。
- 浏览器控制台无未处理错误。

### 4.4 无障碍

- 所有输入框有始终可见标签。
- 键盘焦点清晰且不被遮挡。
- 正文对比度至少 4.5:1。
- 风险、任务和系统状态同时使用文字与颜色。
- 图片和上传证据有替代说明。

### 4.5 文保业务安全

- 不使用精确坐标、安防设施或未公开遗址信息。
- 现场图片支持个人信息脱敏。
- 引用可追溯，无来源时显示“信息不足”。
- AI 结论标记为初判或建议，人工确认和审计记录可查。
