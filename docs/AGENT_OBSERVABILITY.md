# Agent 可观测性

最后更新：2026-09-24

## 1. 记录对象

- AgentRun：输入摘要、状态、开始时间、结束时间、Prompt 版本。
- ModelCall：Provider、模型、耗时、Token、错误码。
- ToolCall：工具名、参数摘要、结果状态、耗时。
- Finding：风险、等级、引用和人工确认结果。

## 2. 隐私

- 不记录密码、密钥和完整文件内容。
- 敏感文字保存摘要或哈希。
- 图片仅记录元数据和内部 ID。
- 日志与业务数据分离，使用请求关联 ID。

## 3. 关键指标

- Agent 成功率。
- Schema 合法率。
- 工具失败率。
- Provider P50/P95 延迟。
- 降级触发次数。
- 人工驳回率和原因。
