# 项目简介：文巡智护

最后更新：2026-09-24

## 1. 项目定位

文巡智护是面向文物建筑巡查与保护整改场景的智能体 Web 系统。它帮助巡查人员制定检查计划、记录现场信息、识别风险、引用公开保护规范、创建整改任务并复核整改证据。

## 2. 目标用户

- 巡查人员：创建巡查、记录现场情况和提交发现。
- 整改责任人：领取任务、提交整改说明和证据。
- 复核人员：确认风险、审核证据、驳回或关闭任务。
- 管理员：维护建筑档案、用户和规范知识库。

## 3. 核心问题

- 巡查记录分散，历史问题难以连续追踪。
- 风险判断依赖个人经验，标准引用耗时。
- 整改过程缺少责任人、期限和证据链。
- 从发现风险到归档缺少完整闭环。

## 4. 核心闭环

```text
创建巡查
  -> 智能体生成检查计划
  -> 巡查人员提交文字和照片
  -> 智能体分析风险并引用规范
  -> 人工确认风险
  -> 创建整改任务
  -> 责任人提交整改证据
  -> 智能体初审整改证据
  -> 人工复核并关闭任务
  -> 生成巡查档案和报告
```

## 5. MVP 范围

- 文物建筑档案和用户角色。
- 巡查任务、现场记录和图片证据。
- 单智能体工作流和六个白名单工具。
- 规范知识库、条款引用和来源追踪。
- 风险发现、整改任务、证据复核和报告。
- 模型失败降级、Agent 运行记录和测试。
- 三栋脱敏模拟文物建筑和完整演示案例。

## 6. 非目标

- 自动结构安全鉴定。
- 自动批准保护修复方案。
- 真实测绘、三维扫描或数字孪生。
- IoT、传感器和无人机接入。
- 多智能体编排。
- 展示精确坐标、安防设施或未公开遗址信息。

## 7. 成功标准

- 四类角色能够在公网 Web 系统完成一条端到端流程。
- 所有风险建议可追溯到知识库条款或明确标记为信息不足。
- 智能体和工具输出通过固定 Schema 校验。
- 模型或网络失败时，演示流程可以降级继续。
- 文档、测试、源码和部署结果保持一致。
