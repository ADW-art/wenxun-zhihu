# 数据来源与授权

最后更新：2026-09-24

## 1. 规范数据

- 国家文物局公开行业标准。
- 全国标准信息公共服务平台。
- 其他明确标注发布机构和版本的公开发布物。

## 2. 图片数据

- 团队自行拍摄的公开区域照片。
- 明确 CC0 或公共领域的开放馆藏图片。
- 取得书面许可的图片。
- 明确标注为合成演示的 AI 图片。

不得使用来源不明的搜索引擎、社交媒体或新闻图片。不得使用限制 AI 创作、App、H5 或小程序展示的影像。

## 3. 业务数据

首版全部使用自建模拟数据。建筑名称使用虚构编号，不保存精确坐标、安防部署、未公开遗址或真实个人资料。

## 4. 记录字段

- 来源名称。
- 原始 URL 或文件编号。
- 作者和发布机构。
- 授权类型。
- 获取日期。
- 是否允许修改和公开展示。
- 版本和更新日期。
