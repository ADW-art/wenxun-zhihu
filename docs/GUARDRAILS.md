# 智能体安全边界

最后更新：2026-09-24

## 1. 输入防护

- 对所有 API 输入进行 Zod 校验。
- 文件和 URL 使用白名单。
- 知识库内容视为不可信数据。
- 检测常见 Prompt Injection 并保留下一步规则。

## 2. 输出防护

- 结构化输出必须通过 Schema。
- 引用必须来自知识库并检查存在性。
- 无依据时返回信息不足。
- 不输出结构安全结论或修复施工参数。

## 3. 工具防护

- 工具白名单和参数白名单。
- 有副作用工具只能创建草案。
- 人工审批后才能写入状态变化。
- 工具继承用户权限，不提升权限。

## 4. 操作防护

- 关闭任务、确认风险和归档需要人工操作。
- 管理员操作记录审计日志。
- 不允许智能体删除业务记录或修改权限。

## 5. 降级

- Provider 失败时返回 Mock 结果并明确标记。
- 检索失败时不生成虚假引用。
- 文件服务失败时保留文字内容并允许重试。
