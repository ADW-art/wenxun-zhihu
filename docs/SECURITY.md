# 安全与合规

最后更新：2026-09-24

## 1. 资产

- 用户账号和会话。
- 巡查记录、整改证据和建筑档案。
- 模型、数据库和对象存储密钥。
- 知识库来源和 Agent 运行记录。

## 2. 主要威胁

- 越权审批、关闭任务或访问其他建筑。
- Prompt Injection 诱导工具越权。
- 上传恶意文件、超大文件或含定位信息的图片。
- 密钥泄漏到客户端、日志或仓库。
- 模型编造规范条款或来源。
- 展示敏感位置、安防信息和未授权图片。

## 3. 缓解措施

- Auth.js HTTP-only 会话和服务端 RBAC。
- Zod 校验所有输入和模型结构化输出。
- 工具白名单、参数白名单和副作用确认。
- 文件类型、大小、扩展名和内容检查。
- 上传前移除 EXIF，默认拒绝定位信息。
- 知识库引用返回条款 ID 和来源 URL，服务端二次校验存在性。
- 日志脱敏，不记录密码、密钥和完整敏感内容。
- 数据演示使用脱敏建筑、CC0 图片和模拟记录。

## 4. 现场降级

- Provider 超时使用 Mock 结果。
- 外部图片不可用时使用本地缓存或自绘示意图。
- 数据库异常时仍显示最近一次成功数据。
