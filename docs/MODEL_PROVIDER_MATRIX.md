# 模型与 Provider 矩阵

最后更新：2026-09-24

真实 Provider 尚未选定。实现时只依赖能力接口，不依赖供应商名称。

| Provider          | 用途                     | 状态       | 约束                               |
| ----------------- | ------------------------ | ---------- | ---------------------------------- |
| Mock              | 本地开发、测试、现场降级 | 已规划     | 确定性结果，不代表真实模型能力     |

## 必需能力

- 文本生成。
- 结构化 JSON 输出。
- 可选工具调用。
- 超时、取消和错误归一化。
- 使用量、耗时和 Provider 元数据记录。

## 选择条件

1. 中文文保知识理解稳定。
2. 支持工具调用和 JSON Schema。
3. 允许公网部署调用。
4. 延迟和成本满足演示。
5. API Key 可由环境变量注入。
