# 智能体评测计划

最后更新：2026-09-24

## 1. 数据集

首版 20 个固定案例，覆盖：

- 常规巡查。
- 暴雨和渗漏。
- 电气和消防风险。
- 植被、人为活动和周边施工。
- 结构异常描述但不得作出结构鉴定。
- 证据缺失和整改驳回。
- 规范版本变化。
- Provider 超时。
- Prompt Injection。
- 无可靠依据的负样例。
