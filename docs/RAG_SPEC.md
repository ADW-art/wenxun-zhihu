# RAG 规格

最后更新：2026-09-24

## 1. 知识来源

- 国家文物局公开文物保护行业标准。
- 全国标准信息公共服务平台公开标准。
- 建筑防火、文物保护、巡查和档案管理规范。
- 项目自行编写的脱敏演示案例。

## 2. 文档处理

```text
来源登记
  -> 版权和版本检查
  -> 条款切分
  -> 元数据标注
  -> 索引
  -> 人工抽检
```

每个条款至少包含：

- `documentId`
- `clauseId`
- `title`
- `text`
- `sourceUrl`
- `version`
- `effectiveDate`
- `buildingTypes`
- `riskTags`

## 3. 检索策略

- 第一层：建筑类型和风险标签过滤。
- 第二层：中文关键词和条款文本检索。
- 第三层：可选向量相似度。
- 返回结果必须包含原文和来源，不允许只返回模型摘要。

## 4. 引用规则

- 引用只能来自检索结果。
- 引用必须经过服务端存在性校验。
- 没有足够依据时返回 `insufficient_evidence`。
- 规范更新后旧版本只读保留，新巡查使用新版本。
