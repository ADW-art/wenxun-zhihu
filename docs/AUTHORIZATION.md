# 权限模型

最后更新：2026-09-24

## 1. 角色

| 角色      | 主要职责                           |
| --------- | ---------------------------------- |
| INSPECTOR | 创建巡查、提交记录和图片           |
| RECTIFIER | 处理分配给自己的整改任务           |
| REVIEWER  | 确认风险、创建任务、复核整改和关闭 |
| ADMIN     | 管理建筑、用户、知识和系统配置     |

## 2. 权限矩阵

| 操作                | INSPECTOR | RECTIFIER | REVIEWER | ADMIN |
| ------------------- | --------: | --------: | -------: | ----: |
| 查看建筑            |        是 |        是 |       是 |    是 |
| 创建巡查            |        是 |        否 |       是 |    是 |
| 提交巡查            |        是 |        否 |       是 |    是 |
| 确认风险            |        否 |        否 |       是 |    是 |
| 创建整改任务        |        否 |        否 |       是 |    是 |
| 提交整改证据        |        否 |        是 |       否 |    是 |
| 关闭整改任务        |        否 |        否 |       是 |    是 |
| 管理规范知识库      |        否 |        否 |       否 |    是 |
| 查看 Agent 运行记录 |        否 |        否 |       是 |    是 |

## 3. 服务端规则

- 权限不得只依赖隐藏按钮。
- 每次状态变化检查角色、资源归属和当前状态。
- 整改责任人只能操作分配给自己的任务。
- Agent 工具使用调用者权限，不绕过业务服务。
